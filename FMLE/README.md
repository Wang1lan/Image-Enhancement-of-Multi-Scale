# Fast Multilayer Laplacian Enhancement · MATLAB 浮点复现

本工程实现 Talebi 与 Milanfar（2016）的两尺度 NLM 分解、共享结构掩模和分层映射。灰度图直接处理，彩色图在原分辨率处理亮度。随附实拍图为 1428×1080 的 8 位 RGB 图像。原文与阅读报告位于工程上两级的 `References` 目录。[论文 DOI](https://doi.org/10.1109/TCI.2016.2607142)

## 运行

在 MATLAB 中执行以下命令。已验证环境为 R2025b 和 Image Processing Toolbox。

```matlab
root = 'D:\Endoscope\图像增强-多尺度\Simulation\FMLE';
addpath(root);
report = run_fmle_tests();    % 无需选图或鼠标操作
demo_fmle                    % 单张实拍图，默认 noisy
demo_fmle_compare            % 实拍图及固定种子的 12 个合成样例
```

单图入口顶部可修改输入文件、预设及参数。比较入口的 `runReal` 和 `runSynthetic` 分别控制实拍图和合成组。默认实拍图已配好 3 个平坦区、3 个纹理区和 3 条边缘剖面。若重新框选，设 `selectRois=true`，在原图上依次画矩形或边缘法向线并双击确认。将生成的 `roi.json` 路径填入 `roiFile` 即可在后续运行复用。换图时可提供该图自己的 ROI 文件或在输入图上选取。

```matlab
addpath(fullfile(root,'functions'));
cfg = fmleDefaultConfig('noisy');
img = readFmleImage(fullfile(root,'testImg','testImg_1.png'));
[out,dbg] = fmleEnhance(img,cfg);        % H×W 或 H×W×3
[Yout,dbgY] = fmleEnhanceY(dbg.Yin,cfg); % H×W
```

`readFmleImage` 读取 PNG、BMP、TIFF、JPEG。带 Alpha 通道的文件会报错。数组入口接受 uint8、uint16、[0,1] 范围内的有限 single 或 double，整型按其类型满量程归一化。低有效位宽数据请按实际标度传入浮点值。输出与浮点中间量均为 double。

## 数值约定

| 环节 | 实现与复现假设 |
|---|---|
| 颜色 | 全范围 BT.709，Y 系数为 0.2126、0.7152、0.0722，Cb、Cr 以零为中心。RGB 重构使用输入色度和限幅后的亮度。亮度限幅按像素统计，RGB 限幅按通道样本统计。 |
| NLM | 搜索窗 5×5，比较块 3×3，包含中心自匹配。原图一次 `replicate` 扩边，按偏移取块并累加。指数为 `exp(-SSD/0.7)`，SSD 为 9 项之和，无空间权重。两尺度始终采样同一输入。 |
| 两尺度 | 默认平方未归一化权重得到第二尺度，分别用各自权重和归一化。`weightMode='direct'` 直接计算第二个指数，用于数值核对。`numScales` 固定为 2。 |
| 近似滤波 | `filterMode='approx'` 使用 `Y+alpha*(A-d.*Y)`，每尺度按式（18）计算全图标量。可设 `alphaMode='eq20'` 选择倒数均值近似。两级平滑保留超界值，超界比例见统计文件。 |
| 结构掩模 | 默认 `M=1-d1/p`，其中 p 为搜索偏移数，默认 25。`maskSource='d2'` 使用第二尺度权重和。`useMask=false` 令有效掩模全一，原始 M 仍可查看。 |
| 映射与融合 | 基础层以 0.5 为中心，有符号细节以 0 为中心。作用区间内使用端点归一化 sigmoid 或其严格逆函数，区间外保持恒等。同一 M 乘在两个映射后的细节层上，再加到映射后的基础层。 |

论文给出了相似性权重、平方复用、掩模表达式及实验参数。BT.709、边界扩展、默认选择 d1 和带宽曲线的具体分段形式是本工程的复现约定。配置及假设随每次运行保存。未与作者实现做逐像素比对。

### 预设

表内括号为 `(a, width)`。线性模式的数值为增益。

| 名称 | 基础层 | 中尺度 | 精细尺度 |
|---|---|---|---|
| noisy | S (5, 0.75) | S (60, 0.45) | 反 S (10, 1) |
| defocus | S (6, 0.75) | S (50, 0.33) | S (20, 0.66) |
| smoothing | 恒等 | S (10, 0.20) | 清零 |
| identity | 恒等 | 恒等 | 恒等 |
| linear | 恒等 | 3 | 1 |

## 实验和输出

每次运行写入 `results/<图名>/<预设或compare>/<时间戳>/`。单图的 `intermediate.mat` 保存完整 `dbg`，包括限幅前的 `Zraw` 和 RGB 重构值。输入和输出以 16 位无损 PNG 导出，定量分析读取 MAT。分解图的两个细节层共用一个对称色轴。映射前后及加权细节图按尺度共用色轴。

比较实验从同一个 noisy 配置派生四个条件。A、B 的精细层用 S，C、D 的精细层用反 S。每对的前一组关闭掩模，后一组启用掩模。四组共享一次精确分解以及全套 ROI。另保存 D 切换 d2、D 切换近似滤波、恒等映射加掩模的结果。清晰图卡和失焦图卡还分别运行 smoothing、defocus 预设。

| 文件 | 内容 |
|---|---|
| `comparison.png`、`roi_comparison.png` | 输入、基底和各条件的整图对照，以及平坦区、纹理区和边缘的代表性局部 |
| `shared.mat`、各条件的 `fusion.mat` | 前者保存共同输入、参考、ROI 及两种滤波分解。后者保存各条件的加权细节、原始亮度输出、限幅后亮度和限幅统计 |
| `config.json`、`roi.json` | 参数、假设、实验条件与 ROI 坐标。矩形为从 1 开始的 [列、行、宽、高]，线段为 [x1,y1,x2,y2] |
| `metrics.csv`、`roi_summary.csv` | 逐 ROI 指标和同类 ROI 等权平均。image 行为全图，分母为零的比值记为 NaN |
| `global_metrics.csv` | 亮度与 RGB 的越界比例、亮度均值变化、掩模范围与 P10/P50/P90。灰度数据的 RGB 项记为 NaN |

高频波动使用整图减去 σ=1 高斯平滑后的残差，在指定 ROI 统计标准差或 RMS。正弦纹理另按已知周期拟合幅值。强边缘过冲/欠冲使用限幅前的输出剖面，以该剖面两端各五分之一的均值估计两侧平台。合成图的 RMSE/PSNR 包含基础层色调映射造成的亮度差异。

## 本次实测

2026-11-27 在 MATLAB R2025b 上从工程目录外运行了两个 demo 和 T01–T12。逐点参考与向量化 NLM 六个输出的最大绝对误差为 `2.66e-15`，各预设正反曲线密集采样互逆最大误差为 `2.28e-12`，RGB 恒等往返最大误差为 `1.11e-16`。实拍图单图入口与比较入口 D 的 16 位 RGB 输出逐像素一致。已验证预设 ROI 及坐标复用，手动鼠标框选尚未实测。[测试报告](results/testImg_1/noisy/20261127_085131_847/test_report.csv)

### 合成图

| 输入与预设 | 实测现象 |
|---|---|
| 五档常量 | NLM 保持常量，两个细节层和 M 为零。noisy 的基础层曲线仍会调整作用区间内的非中心灰阶。 |
| 四档平坦噪声，D | σ 从 0.005 增至 0.04 时，平坦区 M 均值从 0.00061 升至 0.03800。D 的四档高频标准差比分别为 0.1155、0.1153、0.1147、0.1153。σ=0.04 时 B 为 0.1569，D 为 0.1153，此时反 S 曲线对减小精细波动有可见的增量。 |
